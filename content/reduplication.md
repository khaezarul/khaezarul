##### Reduplication of the last syllable

- {i, u, e, o} all become {ë} in the new syllable
- {s} becomes {r} between vowels
- most of the time, when a word ends in {ën, ël, ër}, it is the *next-to-last* syllable that is duplicated instead (mebël => mebël*më* rather than mebël*bë*)
- when a disallowed cluster would be created, the last consonant wins out and the previous one is deleted; however if the deleted one is voiceless (=> {p, t, k, f, s, sh}) the remaining consonant will be made voiceless ({b, d, g} => {p, t, k})

Examples:
- nabi => nabibë
- brem => brembë
- lupsa => lupsara
- chales => chalelë
- lakën => lakënla
- paya => payaya
- dont => dontë
