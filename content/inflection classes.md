### Stem Changes with Prefixes

the word begins with a certain consonant, and when prefixes are added, one of these happens to that first consonant =>

soft => {p, t, k, b, d, g, ts} => {w, s, sh, w, r, sh, sh}
hard => {p, t, k, b, d, g} => {b, d, g, b, d, g}

s => r
{k, g} => h
/ => '

unchanged

---

### Specific Changes

##### -Ce-
there is an intervening syllable between the stem and the suffixes in some forms

-i- in si-form
-i- in past perfective (normally *-tsi*)
-Ce- in mar-form

##### diphthongization
if the word begins with a vowel, and the syllable is reduplicated =>
{e, i} => ei
{o, u} => ou
a => aha

##### -CiR-
the word ends in -CeR, where R is {m, n, ng, r, l}

in any suffixed form, it becomes -CiR instead (seb**e**r / seb**i**rseto)
